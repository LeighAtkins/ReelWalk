ReelWalk in 90 seconds

ReelWalkを90秒で · about 90 seconds

Four parts in a fixed order: product, architecture, reliability, delivery. Pause briefly between parts. The last line states where it runs and what it costs, so nobody has to ask.

  1. ReelWalk(リールウォーク)は、物件紹介のリール動画をスマホで作るアプリです。

    ReelWalk is an app for making property-listing Reels on a phone.

  2. 不動産会社が、外注せずに自分で動画を作れることを目指しました。

    The goal is that agents can make the video themselves instead of outsourcing it.

  3. カットや並べ替え、文字、音楽、360度写真の演出ができます。

    You can cut, reorder, add text and music, and animate 360 photos.

  4. 構成は、Next.js(ネクストジェイエス)のWebアプリと、動画を作るワーカーの二つです。

    It has two parts: a Next.js web app and a worker that renders the video.

  5. 画面はServer Components、更新はすべてServer Actionsです。

    Pages are Server Components, and every change goes through a Server Action.

  6. データはPostgreSQLとPrisma、動画などのファイルはS3に置きます。

    Data lives in PostgreSQL through Prisma; videos and other files go to S3.

  7. 素材は、ブラウザから署名付きURLで、S3に直接アップロードします。

    The browser uploads media straight to S3 with a presigned URL.

  8. 書き出しを押すと、ジョブを保存して、IDだけをSQSに送ります。

    When you press Export, the job is saved and only its ID is sent to SQS.

  9. SQSは、同じメッセージが二回届くことがあります。

    SQS can deliver the same message twice.

  10. そのため、ワーカーは冪等(べきとう)に作りました。

    So I made the worker idempotent.

  11. 状態は条件付きで更新するので、二重に完了することはありません。

    Status changes are conditional updates, so a job can never complete twice.

  12. ローカルはHelm(ヘルム)とkind(カインド)、本番はTerraformでAWSにデプロイしています。

    Locally it runs with Helm on kind; production is deployed to AWS with Terraform.

  13. GitHub Actionsで、テストと脆弱性(ぜいじゃくせい)スキャン、E2Eテストを回しています。

    GitHub Actions runs the tests, vulnerability scans and end-to-end tests.

  14. 本番はApp Runner(アップランナー)と、必要なときだけ動くFargate(ファーゲート)で、月十ドル台で運用しています。

    Production runs on App Runner and Fargate tasks that only run when needed, for ten-something dollars a month.

To memorise: play it twice, shadow it once, then turn on Hide Japanese and say each line before tapping to check.
