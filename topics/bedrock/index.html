How to explain it

  1. Bedrockは、AWSの生成(せいせい)AIのサービスです。

    Bedrock is AWS's generative AI service.

  2. ClaudeなどのモデルをAPIで呼べます。

    You can call models such as Claude through an API.

  3. ReelWalkでは、AI機能はまだ作っていません。

    ReelWalk has no AI features yet.

  4. 考えているのは、キャプションの下書(したが)きです。

    What I have in mind is drafting captions.

  5. 物件の情報から、Instagram用の文章を提案します。

    It would suggest Instagram text from the listing details.

  6. 呼び出しはワーカー側で、非同期(ひどうき)にするつもりです。

    I'd make the call from the worker, asynchronously.

  7. 結果は提案として見せて、必ず人が確認します。

    The result is shown as a suggestion and always checked by a person.

Why ReelWalk uses it

  1. キャプションを書くのは、不動産(ふどうさん)の担当者には手間です。

    Writing captions is a chore for real-estate agents.

  2. Bedrockなら、AWSの中でIAMで権限を管理できます。

    With Bedrock, access is managed with IAM inside AWS.

  3. ただ、住宅(じゅうたく)の広告は表現のルールが厳しいので、確認が必須です。

    But housing ads have strict wording rules, so review is a must.

Interview questions

AIの機能は、もう使っていますか？Do you already use AI features?

  1. いいえ、まだ実装していません。

    No, not yet implemented.

  2. 案としては、キャプションの下書きを考えています。

    The idea is caption drafts.

  3. 優先度(ゆうせんど)を下げて、まだ試していません。

    I lowered its priority and have not tried it yet.

Answer 'no' cleanly first. An honest 未実装 followed by a sensible plan is far better than vagueness.

入れるとしたら、どう組み込みますか？If you added it, how would you wire it in?

  1. レンダーと同じで、キューとワーカーを使います。

    The same way as rendering: a queue and a worker.

  2. モデルの応答は遅いので、Webでは待ちません。

    Model responses are slow, so the web request doesn't wait.

  3. 物件の項目だけを渡して、事実を作らせないようにします。

    I'd pass only the listing fields so it can't invent facts.

  4. 結果は、今のInstagramのチェックにも通します。

    The result also goes through the existing Instagram checks.

生成AIのリスクは、どう考えますか？How do you think about the risks of generative AI?

  1. 一番は、間違った物件情報を書くことです。

    The biggest is writing wrong facts about a property.

  2. あと、住宅の広告では、買う人を選ぶ表現は禁止です。

    Also, housing ads may not express a preference for who buys.

  3. なので、必ず人が確認してから使います。

    So a person always reviews it before use.

  4. コストも、トークンの上限で管理します。

    Cost is controlled with token limits.
